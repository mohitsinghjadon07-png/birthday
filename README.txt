BANNISA'S BIRTHDAY SURPRISE

Files
- index.html: the complete, self-contained birthday website.

How to use
1. Open index.html in a modern browser to test it.
2. PIN: 0511.
3. On the memories screen, use “Add your photos” to select up to four pictures.
   Note: selected photos are previewed locally in the current browser session;
   they are not uploaded or saved into the website. For a shareable hosted page,
   add the actual photos to the project and update the gallery markup.
4. The music is an original, simple synthesized melody made with Web Audio.
   Browsers require a tap/click before audio can start. It starts after the correct PIN
   is entered, and can be toggled with the music-note button.
5. The countdown is set for 5 November 2026 at midnight India Standard Time.

Publish
- Upload index.html to a GitHub repository and enable GitHub Pages, or drag the
  folder into a static hosting service such as Netlify.
- If you want her to see your actual memories, put the selected photos into the
  project and replace the photo placeholders before publishing.
